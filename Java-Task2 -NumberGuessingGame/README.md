# Number Guessing Game 

OIBSIP Java Development Internship, Task 2.

## About 
A console game where the computer picks a random number and the player guesses it, with Too High / Too Low hints. 

## Features 
- Random number generated each round
- Higher/lower hints after every guess
- Attempt counter and maximum attempts limit
- Three difficulty levels: Easy (1-50, 10 attempts), Medium (1-100, 7 attempts), Hard (1-200, 5 attempts)
- Play again option 
- Round-by-round score summary
- Input validation for invalid entries
